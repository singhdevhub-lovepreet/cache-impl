Spring Boot Teaching Demos

Interactive demos for WebSocket, Async Programming, and Server-Sent Events.

1. Async Programming

CompletableFuture @Async ThreadPool

Compare synchronous vs asynchronous execution. See how three tasks taking 2s + 1.5s + 3s complete in ~6.5s sequentially but only ~3s in parallel. Also demonstrates CompletableFuture composition with thenApply and thenCombine.

Open Async Demo

2. Server-Sent Events (SSE)

EventSource SseEmitter One-way streaming

Subscribe to a server event stream. When a new user is created (via curl or API), the event is pushed to all connected browsers over a single long-lived HTTP connection. Server-to-client only.

Open SSE Demo

3. WebSocket (STOMP)

SockJS STOMP Bidirectional

Full-duplex communication over WebSocket. Send a ping message and get a pong response. Also receives real-time notifications when users are created. Open in two tabs to see broadcasts.

Open WebSocket Demo

Integration Test

Open both SSE and WebSocket demos side by side, then create a user:

curl -X POST http://localhost:8080/v1/users \
  -H "Content-Type: application/json" \
  -d '{"name":"Alice","email":"alice@test.com"}'

Both pages will update simultaneously via the event bridge:
UserService -> ApplicationEvent -> EventListener -> [WebSocket, SSE]
